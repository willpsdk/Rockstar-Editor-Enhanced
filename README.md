A plugin for GTA 5 Legacy & FiveM that upgrades the Rockstar Editor.

- Record longer clips
- Keep recording after you die or tab out.
- Free camera on first-person clips
- No camera collision and no distance limit
- Buildings and detail load around the camera, not the player
- No watermark on exports
- Continuous recording, even when tabbed out
- Higher export quality: new Higher and Max bitrate options, plus 120 FPS

Every feature can be turned on or off in the .ini provided.

Installation Guide:

Singleplayer:

Install ScripthookV, create a 'mods' folder in the games root folder, drop RockstarEditorEnhanced.asi & .ini in that folder and launch the game!

FiveM:

Open Run, type in localappdata (make sure to put the percent symbol at the start and end of that, GTA5Mods doesnt allow it in descriptions lmao) which will open File Explorer, go to the FiveM folder, Go into FiveM Application Data, Place all contents of the download in plugins

THIS ONLY WORKS FOR GTA LEGACY AND FIVEM LEGACY!
